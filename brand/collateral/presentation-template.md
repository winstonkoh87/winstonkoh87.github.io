# Presentation Deck Template Specification

> **Purpose**: Brand-consistent slide deck for client presentations, pitches, and internal use.

---

## Slide Dimensions

- **Aspect Ratio**: 16:9 (1920 × 1080px)
- **Safe Zone**: 80px margin on all sides

---

## Slide Templates

### 1. Title Slide

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│    Λ                                                        │
│                                                             │
│    [PRESENTATION TITLE]                                     │
│    Subtitle or date                                         │
│                                                             │
│                                                             │
│                                    Winston Koh              │
│                                    AI Systems Architect     │
└─────────────────────────────────────────────────────────────┘
```

- **Background**: Void (#0A0A0A)
- **Logo**: Lambda (top-left, gradient)
- **Title**: Outfit Bold, 64px, gradient text
- **Subtitle**: Inter Regular, 24px, Ash (#A1A1AA)
- **Author**: Inter Medium, 18px, Snow (#E8E8E8)

---

### 2. Section Divider

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                                                             │
│              01. [SECTION TITLE]                            │
│                                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

- **Background**: Obsidian (#111111)
- **Number**: Outfit Bold, 120px, Electric Blue (#3B82F6), opacity 20%
- **Title**: Outfit SemiBold, 48px, Snow

---

### 3. Content Slide (Text + Visual)

```
┌─────────────────────────────────────────────────────────────┐
│  [SLIDE TITLE]                                              │
│  ─────────────────────────────────────────────              │
│                                                             │
│  • Bullet point one with key insight                        │
│  • Bullet point two with supporting data                    │
│  • Bullet point three with call to action                   │
│                                                             │
│                                       [IMAGE/CHART]         │
│                                                             │
│                                                     Λ   01  │
└─────────────────────────────────────────────────────────────┘
```

- **Title**: Outfit SemiBold, 36px, Snow
- **Divider**: 2px line, Electric Blue (#3B82F6)
- **Body**: Inter Regular, 20px, Ash
- **Bullets**: Electric Blue squares
- **Page number**: JetBrains Mono, 14px, Ash

## Typography Quick Reference

| Element | Font | Weight | Size |
|---------|------|--------|------|
| Title | Outfit | Bold (700) | 64px |
| Section Header | Outfit | SemiBold (600) | 48px |
| Slide Title | Outfit | SemiBold (600) | 36px |
| Body | Inter | Regular (400) | 20px |
| Caption | Inter | Regular (400) | 14px |
| Code/Data | JetBrains Mono | Regular (400) | 14px |

---

## Export Formats

- **Keynote**: `.key` (primary for Mac)
- **PowerPoint**: `.pptx` (for client compatibility)
- **PDF**: Export at 150 DPI for sharing
- **Google Slides**: Import from `.pptx`
